The V2 refresh

Built different this time.

An updated interface is only part of the story. These are some of the bigger changes across Silly V2.

01 / INTERFACE

A proper module layout

Cleaner navigation across Legit, Rage, Visuals, Movement, Misc, and Settings. Less clutter, more control.

02 / CUSTOMIZATION

Go beyond ordinary skins

Viewmodel position and FOV, a custom GLB player model importer, and advanced per-material visual settings.

03 / WORLD

Weather that belongs in the map

Native-depth fog, a darker nighttime scene, and custom rain, snow, and floating particle effects.
